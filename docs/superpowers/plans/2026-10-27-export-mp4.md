# Hardware-Accelerated MP4 Export Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement hardware-accelerated MP4 video export using WebCodecs (H.264 VideoEncoder & AAC AudioEncoder), offline WebGPU frame rendering, `mp4-muxer`, preset resolution profiles, and an interactive Export UI modal with progress tracking and Finder integration.

**Architecture:**
- Frontend export engine (`export_engine.ts`) renders composition frames sequentially using WebGPU offscreen rendering, pipes rendered canvases into `VideoFrame` -> `VideoEncoder` (H.264 AVC), mixes audio clips into `OfflineAudioContext` -> `AudioData` -> `AudioEncoder` (AAC), and muxes them into an MP4 container via `mp4-muxer`.
- Rust backend (`export.rs`) handles secure file storage in `<project_root>/out/<filename>.mp4` and returns the file path.
- UI layer (`ExportModal.svelte`) offers export presets (1080p, 4K, 9:16 Shorts/Reels, Composition native), displays progress %, and allows cancellation or revealing the exported MP4 in macOS Finder.

**Tech Stack:**
- WebCodecs (`VideoEncoder`, `AudioEncoder`, `VideoFrame`, `AudioData`)
- `mp4-muxer`
- WebGPU / Canvas
- Tauri 2 + Rust
- `@tauri-apps/plugin-opener` (`revealItemInDir`)
- Svelte 5 + Vitest

**Spec:** `docs/superpowers/specs/2026-10-27-liosvideo-design.md` (Section 11)

## Global Constraints
- Target platform: macOS (Apple Silicon & Intel).
- MP4 format: H.264 video (`avc1.640028`), yuv420p, faststart ("in-memory").
- Deterministic frame rendering: frame $N$ rendered offline must match preview pixel-for-pixel.
- Export output directory: `<project_root>/out/`.
