# Timeline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An interactive timeline under the preview. It shows the scene track and each scene's expandable object tree with animation spans. Clicking a scene or object selects it (shown as a selection chip in the chat pane) and seeks the playhead. Selections survive reloads because node paths are stable.

**Architecture:** The runtime derives a `TimelineManifest` from a composition (scenes → object trees → animation spans in composition frames), using the stable node paths from the foundation. The render worker sends the manifest with every `loaded` message. The desktop side has a pure timeline model (visible rows, pixel layout, x↔frame, selection reconciliation) and a thin Svelte `Timeline` component. Selection lives in a small shared state module that the future chat pane will read.

**Tech Stack:** existing foundation (TypeScript runtime, Svelte 5, Vitest node + browser mode), plus `vitest-browser-svelte` for component tests.

**Spec:** `docs/superpowers/specs/2026-10-27-liosvideo-design.md` (§9.4 timeline derivation, §6 right pane timeline + selection chip, §8.4 selection context shape)

## Global Constraints

- Code is the source of truth. The timeline is derived by evaluating the composition and is never edited (spec §7).
- Node ids/paths must be stable across re-evaluation so selections survive edits (spec §9.4).
- Selection carries: composition file, scene id, node path (optional), time range (spec §8.4).
- Audio tracks are out of scope here (audio plan).

## Review Focus

1. **Selected node renamed or removed by a reload** → the selection falls back to its scene if the scene still exists, otherwise it is cleared. Never a dangling path. Test in Task 3.
2. **Empty composition / scene with no children** → the timeline renders an empty state, no exceptions. Tests in Tasks 1 and 4.
3. **Instant changes (`set()`, zero-length spans)** → still visible and clickable (minimum marker width). Test in Task 3.
4. **Large trees** → rows are collapsed by default, and only expanded subtrees are flattened. Test in Task 3.
5. **Clicks outside the track area** (x < 0 or beyond the end) → frame clamps to `[0, totalFrames-1]`. Test in Task 3.

### Task 1: Manifest derivation in the runtime

**Files:**
- Modify: `packages/runtime/src/anim/track.ts`, `packages/runtime/src/graph/node.ts`, `packages/runtime/src/index.ts`
- Create: `packages/runtime/src/manifest.ts`
- Test: `packages/runtime/test/manifest.test.ts`

**Interfaces:**
- Produces:
  - `Track.segments(): readonly Segment<T>[]`
  - `Node.spans(): { start: number; end: number }[]`: seconds, sorted, overlapping/touching segments of all props merged. Zero-length segments are kept as `start === end`.
  - ```ts
    type ManifestNode = { path: string; name: string; kind: string; spans: { startFrame: number; endFrame: number }[]; children: ManifestNode[] };
    type ManifestScene = SceneSpan & { tree: ManifestNode };
    type TimelineManifest = { width: number; height: number; fps: number; totalFrames: number; scenes: ManifestScene[] };
    buildManifest(c: Composition): TimelineManifest
    ```
  - Frames: `startFrame = scene.startFrame + Math.round(start * fps)`, `endFrame = scene.startFrame + Math.round(end * fps)`, both clamped to the scene's `[startFrame, endFrame]`.

- [ ] **Step 1: Write failing tests:**
  - `spans()` merges `to({x},{at:0,duration:1})` and `to({opacity},{at:0.5,duration:1})` into `[{start:0,end:1.5}]`. Separate segments stay separate. `set({}, 2)` gives `{start:2,end:2}`.
  - `buildManifest` on 2 scenes at 30 fps (2 s, 1 s). The second scene's tree root path is the scene id, the children's paths match `Node.path()`, a child animated at 0.5–1 s has `spans [{startFrame:75,endFrame:90}]`, and a span running past the scene end is clamped.
  - An empty composition gives `{scenes: [], totalFrames: 0}`. A scene without children has `tree.children` = `[]`.
  - Determinism: `buildManifest` twice on separately constructed equal compositions deep-equals.

### Task 3: Pure timeline model

**Files:**
- Create: `apps/desktop/src/lib/timeline/model.ts`
- Test: `apps/desktop/src/lib/timeline/model.test.ts`

**Interfaces:**
- Consumes: `TimelineManifest`, `ManifestNode` (Task 1).
- Produces:
  - `type Selection = { composition: string; sceneId: string; path?: string; startFrame: number; endFrame: number }`
  - `type Row = { key: string /*scene id or node path*/; sceneId: string; path?: string; label: string; depth: number; expandable: boolean; expanded: boolean; spans: { startFrame: number; endFrame: number }[] }`
  - `visibleRows(m: TimelineManifest, expanded: Set<string>): Row[]`: one row per scene (depth 0, its span = the scene range). The children of an expanded key follow at depth+1. The scene root group itself is not a separate row (scene row = root).
  - `spanToPx(span, totalFrames, widthPx): { x: number; width: number }`: `width = max(MIN_MARKER_PX, …)`, `MIN_MARKER_PX = 3`.
  - `frameAtX(x: number, widthPx: number, totalFrames: number): number` (clamped).
  - `selectionFor(row: Row, composition: string, m: TimelineManifest): Selection`: a scene row gets the scene range. A node row gets the union of its spans and its descendants' spans, or else the scene range.
  - `reconcileSelection(sel: Selection | undefined, composition: string, m: TimelineManifest): Selection | undefined`: different composition → unchanged. Path still exists → refreshed ranges. Path gone but scene exists → scene selection. Scene gone → `undefined`.
  - `selectionLabel(sel: Selection): string` → `"long.ts › install-extension › desktop/terminal"` (path shown relative to the scene root, scene-only when no path).

- [ ] **Step 1: Write failing tests**, one per function above, including the Review Focus cases:
  - `frameAtX(-10, …) === 0`, `frameAtX(9999, 100, 90) === 89`
  - zero-length span width `3`
  - collapsed scenes give only scene rows even with deep trees (1 scene, 500 nested nodes → 1 row)
  - renamed node falls back to scene; removed scene → `undefined`
  - empty manifest → `[]`
- [ ] **Step 2: Run** `pnpm --filter desktop vitest run timeline` → FAIL.

**Files:**

- Test: `apps/desktop/src/lib/components/Timeline.browser.test.ts`

**Interfaces:**
- Consumes: Task 3 model, `LoadedInfo.manifest` (Task 2).
- Produces:
  - `selection.svelte.ts`: `export const selection: { current: Selection | undefined }` (a `$state` object), `select(s: Selection | undefined): void`.
  - `Timeline.svelte` props: `{ manifest: TimelineManifest; composition: string; frame: number; selected?: Selection; onSelect: (s: Selection) => void; onSeek: (frame: number) => void }`. Internal `expanded` set. Row header column 180 px (label, disclosure triangle) and a track area with span bars and a playhead line. Clicking a row header or bar → `onSelect(selectionFor(...))` + `onSeek(selection.startFrame)`. Clicking empty track area → `onSeek(frameAtX(...))`. The selected row is highlighted. Empty manifest → "No scenes".
  - `SelectionChip.svelte` props: `{ selection?: Selection; onClear: () => void }`, showing `selectionLabel` and a ✕ button. Escape anywhere (outside inputs) clears the selection.
