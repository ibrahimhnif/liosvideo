# Audio & TTS Engine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Audio & TTS Engine for liosvideo so compositions can define narration and background audio tracks with sample-accurate Web Audio playback, and ACP agents can generate voice lines with word-level timestamps via MCP tools (`tts_generate`, `tts_list_voices`).

**Architecture:** Compositions declare audio tracks (`AudioTrack`, `AudioClip`) with timing anchored to composition frames or narration lines (`vo(lineId)`). The desktop preview synchronizes a Web Audio `AudioContext` with `PlaybackClock`. On the Rust backend, a pluggable `TtsProvider` system generates audio files and word timing JSON files in `assets/audio/vo/`, exposed to agents via the Editor MCP server.

**Tech Stack:** TypeScript, Web Audio API, Rust (Tauri 2, Tokio, `serde`, `serde_json`, `reqwest`), Vitest & Cargo test.

**Spec:** `docs/superpowers/specs/2026-10-27-liosvideo-design.md` (§8.3 MCP tools, §9.1, §10 Audio).

## Global Constraints

- Audio timing must remain sample-accurate and deterministically synchronized with the video playhead.
- Generated voice files stored in `assets/audio/vo/<line-id>.mp3` with corresponding `<line-id>.timing.json` word timestamps.
- MCP tools `tts_generate` and `tts_list_voices` conform to MCP specification.
- Local/mock synthesizer included so all tests and offline use run without requiring external cloud API keys.

```typescript
import { describe, expect, it } from "vitest";
import { composition, scene } from "../src/composition";
import { buildManifest } from "../src/manifest";
import { vo } from "../src/audio/timing";

describe("Runtime Audio Model", () => {
  it("includes audio tracks in composition and manifest", () => {
    const comp = composition({
      width: 1920,
      height: 1080,
      fps: 30,
      scenes: [scene("intro", { duration: 5.0 }, () => {})],
      audio: [
        {
          id: "narration",
          name: "Narration",
          clips: [{ src: "assets/audio/vo/line-1.mp3", startFrame: 0, duration: 4.0, volume: 1.0 }],
        },
      ],
    });

    const manifest = buildManifest(comp);
    expect(manifest.audioTracks).toBeDefined();
    expect(manifest.audioTracks?.length).toBe(1);
    expect(manifest.audioTracks?.[0].clips[0].endFrame).toBe(120);
  });

  it("calculates word timestamps with vo() helper", () => {
    const timing = {
      lineId: "line-1",
      duration: 3.0,
      words: [
        { word: "Welcome", start: 0.1, end: 0.6 },
        { word: "to", start: 0.7, end: 0.9 },
        { word: "Liosvideo", start: 1.0, end: 1.8 },
      ],
    };

    const helper = vo("line-1", timing);
    expect(helper.start).toBe(0);
    expect(helper.end).toBe(3.0);
    expect(helper.word("Liosvideo").start).toBe(1.0);
    expect(helper.word("Liosvideo").end).toBe(1.8);
  });
});
```
